# LifeCost v3

A browser-based real-cost-of-purchase calculator.

## What it calculates

LifeCost estimates:
- Net cost after maintenance and expected resale
- Cost per use
- Cost per day
- Cost per month
- Average cost per year
- Estimated total number of uses
- A simple cost breakdown

## Run

Open `index.html`.

## Files

- index.html
- styles.css
- script.js
- README.md

All calculations happen in the browser. No account or backend is required.
