How to Compare Two Products

A side-by-side comparison is more useful when both products are measured using the same assumptions.

Use the same inputs

For both products, estimate the price, useful life, usage frequency, maintenance and expected resale value using the same time and usage assumptions.

Compare net cost

A simple net-cost calculation can include purchase price plus maintenance over the ownership period, minus expected resale value.

Compare cost per use

Estimated cost per use can help show how ownership cost changes when one product is used more often or lasts longer.

Look beyond the numbers

Features, reliability, warranty, compatibility and personal requirements can matter even when the calculated costs are similar.
